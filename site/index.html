DSH VERIFY KIT

五个确定性交付检查

Agent 已经产出结果、人准备验收的那一刻，这五个检查各自决定一件事。每个都是单个命令，从文件本身判定，不调用任何模型。

检查清单npm 包它决定什么
交付文件校验清单（SHA-256 manifest）dsh-hashcheck交付出去的 bytes 和你验收过的 bytes 是否还是同一份
报告引用检查清单dsh-citelint引用编号、来源与本地链接是否自洽
文档结构检查清单dsh-outline-lint这份文档在结构上是否可审
Markdown 表格检查清单dsh-tablelint每张表的每行单元格数是否与表头一致
文档内数字写法一致性检查dsh-numberlint同一数量在文档内是否只有一种写法

为什么是五个独立的包

一份交付通常只需要其中一两个。装五个用一个，和装一个用五个，是两种不同的依赖负担。每个包：主函数 + CLI + host 路由，出口码 0/1/2，--json 出机器结果。规则与测试一一对应，页面上的规则表来自测试套件，不会漂移。

垂直行业的检查（合同、发票、电商）在 dsh-vertical-kit。
