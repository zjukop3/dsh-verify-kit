DSH VERIFY KIT · dsh-hashcheck

交付文件校验清单（SHA-256 manifest）

它决定一件事：交付出去的 bytes 和你验收过的 bytes 是否还是同一份。

检查规则

规则判定
changed清单里有、磁盘上也有，但哈希对不上 → error，报前后摘要
missing清单里有、磁盘上没有 → error
unlisted磁盘上有、清单里没有 → warn（交付后混进来的文件）
size-mismatch哈希相同但记录的字节数不符 → warn（顺手核对，极少出现）

用法

npx dsh-hashcheck build ./delivery --out delivery/hashcheck.json --ignore node_modules
npx dsh-hashcheck verify delivery/hashcheck.json --dir ./delivery

出口码：0 干净、1 有发现、2 用法或读文件错误。--json 输出机器可读结果，--warnings-fail 让警告也算失败。DSH 内同样的函数在 POST /hashcheck/api（{"text":"…"} 或 {"path":"…"}），面板与 CI 调同一实现，不可能不一致。

这是清单，不是专业人士。每条发现都是文件里可判定的结构缺陷，带行号或路径；它从不说「内容好不好」。
清单本身是确定性的：路径排序、正斜杠、无时间戳，同一目录在任何机器上生成同一份清单，可以直接 diff。 · dsh-verify-kit 全部五个检查
