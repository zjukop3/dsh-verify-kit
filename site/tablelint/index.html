DSH VERIFY KIT · dsh-tablelint

Markdown 表格检查清单

它决定一件事：每张表的每行单元格数是否与表头一致。

hashcheckcitelintoutline-linttablelintnumberlintGitHub 源码npm

检查规则

规则判定
column-count某行单元格数与表头不符 → error，报行号
delimiter-count分隔行数量与表头不符 → error
single-column只有一列的「表格」→ warn（那是列表）
duplicate-header两列同名 → warn
empty-header某列没有表头 → warn
empty-table只有表头没有数据行 → warn

用法

npx tablelint report.md --json
npx tablelint report.md --warnings-fail

出口码：0 干净、1 有发现、2 用法或读文件错误。--json 输出机器可读结果，--warnings-fail 让警告也算失败。DSH 内同样的函数在 POST /tablelint/api（{"text":"…"} 或 {"path":"…"}），面板与 CI 调同一实现，不可能不一致。

这是清单，不是专业人士。每条发现都是文件里可判定的结构缺陷，带行号或路径；它从不说「内容好不好」。
支持转义竖线（\|），代码块里的表格不参与检查—— fenced code 内的示例不该被当成缺陷。 · dsh-verify-kit 全部五个检查
